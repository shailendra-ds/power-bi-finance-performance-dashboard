# power-bi-finance-performance-dashboard

An interactive Power BI dashboard for exploring sales performance against targets, monthly trends, variance, and salesperson results.

## Overview

This project presents a finance and sales performance report built in Power BI. It brings key metrics and trends together to help users review performance at a glance and explore results by product.

## Dashboard Features

- **KPI cards:** Total actual sales, total target sales, variance, variance percentage, and months target reached
- **Monthly comparison:** Actual sales versus target sales
- **Salesperson table:** Actuals, targets, variance percentage, and trends
- **Product slicer:** Filter the report by product
- **Smart narrative:** Automatically generated summaries of notable performance trends

## Tools

- Microsoft Power BI

## Key Metrics

- **Total Actual Sales:** Actual sales for the selected report context
- **Total Target Sales:** Sales target for the selected report context
- **Variance:** Difference between actual sales and target sales
- **Variance %:** Percentage difference between actual sales and target sales
- **Months Target Reached:** Number of months in which actual sales met or exceeded the target

## Notes

Values and trends respond to the selected product and any other report filters.
